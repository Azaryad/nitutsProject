# nitutsProject

Course project for learning Claude Code, the Anthropic Agent SDK, and multi-agent workflows.

## Project Purpose

Hands-on exercises and experiments with:
- Claude Code CLI and its features (hooks, slash commands, MCP servers)
- Claude Agent SDK — building and orchestrating sub-agents
- Claude API / Anthropic SDK usage patterns

## Repository Structure

```
nitutsProject/
├── CLAUDE.md          # This file — project instructions for Claude Code
├── README.md          # Public-facing project overview
├── .gitignore
└── docs/              # Course notes, references, and experiment write-ups
```

## Working Conventions

- Primary branch: `main`
- Keep docs/ updated with learnings and experiment results
- Commit messages: short imperative sentence (e.g. "Add sub-agent routing example")

## Environment

- Platform: Windows 11, PowerShell
- Shell: PowerShell (use `$env:VAR` syntax, backtick for line continuation)
