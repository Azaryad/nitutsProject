# nitutsProject

A course project for learning to work with the Claude Code system and sub-agents.

## Topics Covered

- Claude Code CLI — features, hooks, slash commands, MCP servers, IDE integrations
- Claude Agent SDK — building custom agents and multi-agent pipelines
- Claude API — tool use, prompt caching, streaming, and Anthropic SDK patterns

## Structure

| Path | Contents |
|------|----------|
| `docs/` | Notes, references, and write-ups from course exercises |
| `CLAUDE.md` | Project instructions for Claude Code |

## Getting Started

```bash
# Clone
git clone git@github.com:Azaryad/nitutsProject.git
cd nitutsProject

# Open in Claude Code
claude .
```
